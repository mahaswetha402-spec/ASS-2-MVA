# ASS-2-MVA

Probability Theory – Conditional Probability

Project Overview

This project demonstrates the concepts of Probability, Joint Probability, and Conditional Probability using Python.

Two spike time series (A and B) are generated using NumPy. Their probabilities are calculated and visualized using Matplotlib.

Objectives

- Understand basic Probability.
- Generate two time series using Python.
- Calculate the probability of event A and event B.
- Calculate Joint Probability.
- Calculate Conditional Probability.
- Visualize the time series using graphs.

Concepts Covered

1. Probability

Probability is the chance of an event happening.

2. Joint Probability

Joint Probability is the probability of two events happening together.

Formula:

P(A ∩ B) = P(A and B)

3. Conditional Probability

Conditional Probability is the probability of one event happening when another event has already happened.

Formulas:

- P(A|B) = P(A ∩ B) / P(B)
- P(B|A) = P(A ∩ B) / P(A)

Technologies Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

Implementation

The project performs the following steps:

1. Import Python libraries.
2. Generate two spike time series (A and B).
3. Set the total number of data points to 10,000.
4. Visualize both time series using a graph.
5. Calculate P(A), P(B), and P(A ∩ B).
6. Calculate P(A|B) and P(B|A).
7. Display the probability results.

Output

The project displays:

- Time series graph for A and B.
- Probability of A.
- Probability of B.
- Joint Probability of A and B.
- Conditional Probability P(A|B).
- Conditional Probability P(B|A).
